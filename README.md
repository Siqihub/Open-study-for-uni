# Open Study For Uni

一个基于 UniApp 开发的图片水印添加工具，支持手机 App 和电脑网页端使用。

## 功能特点

### 核心功能
- **批量图片处理**：支持同时处理多张图片，最多 9 张
- **智能水印添加**：自动在图片右下角添加时间戳和地点水印
- **预览后保存**：处理结果先预览，确认无误后再保存到相册
- **一键刷新**：重新生成所有图片水印，解决偶发的切图问题
- **单张重处理**：双击预览图片可单独重新处理该图片

### 水印设置
- **时间设置**：
  - 支持自定义年、月、日、时、分
  - 开启随机时间后，会在基础时间上增加 0-10 分钟随机偏移
  - 模拟真实拍照时间场景

- **地点设置**：
  - 手动输入地点名称
  - 自动保存历史记录，按使用频率排序
  - 支持快速选择历史地点

- **字体设置**：
  - 提供 8 种字体选择（系统默认、宋体、黑体、楷体、仿宋、微软雅黑、Arial、Helvetica）
  - 实时预览字体效果
  - 可调节字体大小（通过滑块控制）

### 图片管理
- **相册选择**：直接从手机相册选择图片（支持多选）
- **长按多选删除**：长按图片进入多选模式，可批量删除
- **图片预览**：点击已选图片可预览大图
- **清除预览**：可清除当前预览结果，重新选择图片

## 技术栈

- **框架**：UniApp（Vue 3）
- **平台支持**：Android App、iOS App、H5 网页
- **核心 API**：
  - Canvas 绘图（`uni.createCanvasContext`）
  - 图片处理（`uni.getImageInfo`、`uni.canvasToTempFilePath`）
  - 文件保存（`uni.saveImageToPhotosAlbum`）
  - 图片选择（`uni.chooseImage`）

## 安装与运行

### 环境要求
- HBuilderX 3.0+
- Node.js 14+

### 本地运行
1. 克隆项目
```bash
git clone https://github.com/Siqihub/Open-study-for-uni.git
```

2. 使用 HBuilderX 打开项目

3. 运行到手机或模拟器
   - 点击菜单栏「运行」→「运行到手机或模拟器」→「选择设备」

4. 运行到浏览器（H5）
   - 点击菜单栏「运行」→「运行到浏览器」→「Chrome」

### 打包发布

#### Android App
1. 在 HBuilderX 中点击「发行」→「原生 App-云打包」
2. 配置证书信息
3. 等待打包完成，下载 APK 文件

#### H5 网页
1. 在 HBuilderX 中点击「发行」→「网站-H5手机版」
2. 配置域名信息
3. 将生成的 `unpackage/dist/build/h5` 目录部署到服务器

## 使用说明

### 手机 App 端
1. 打开应用，点击「选择图片」从相册选取照片
2. 设置水印参数（时间、地点、字体、大小）
3. 点击「批量处理」生成预览
4. 确认无误后点击「保存」存入相册

### 电脑网页端
1. 在浏览器中打开部署的 H5 页面
2. 点击「选择图片」从电脑文件夹选取照片
3. 设置水印参数
4. 点击「批量处理」生成预览
5. 点击「保存」下载处理后的图片

## 注意事项

1. **图片尺寸限制**：为保证处理速度，过大的图片会自动压缩至 1920px 以内
2. **保存权限**：App 端需要存储权限才能保存图片到相册
3. **字体兼容性**：部分自定义字体在不同平台显示效果可能有差异
4. **预览黑屏问题**：如遇到预览黑屏，可尝试双击重新处理或一键刷新
